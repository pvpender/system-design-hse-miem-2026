## Отсев

В таблице представлены изначальные формулировки и их итоговые варианты.

| Начальная формулировка                                                                                                       |                                                                                   Исправленная формулировка |
| :--------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------: |
| Keeps track of inventory of materials and parts                                                                              |                                       Позволяет вести статистику учёта запчастей с формированием отчётности |
| Routing system to know where the parts are in their manufacturing process                                                    | Интерактивная панель позволяющая просматривать на каком этапе производства используются различные материалы |
| Tracks the time of each part at each station throughout the manufacturing process                                            |                          Система, позволяющая собирать статистику и метрика с различных частей производства |
| Need to identify and track defects in the process and suggestion potential methods to improve quality or avoid in the future |                       См. выше + возможность задавать желаемые метрики. Система указывает отклонения от них |
| Identify materials qualities and make recommendations of better quality materials suppliers                                  |                                                                                                    См. выше |
| Generates costing reports and suggests where costing issues exist                                                            |                                  Формирует финансовую отчётность с указанием отклонений от заданных величин |

## Нефункциональные требования

|                                Требование                                 |
| :-----------------------------------------------------------------------: |
| Решение должно быть масштабируемым для различных производственных цепочек |
|                                SLA 99.9 %                                 |
|                Latency не более 2 секунд для 98% запросов                 |
|                       Резервное копирование данных                        |
|               Возможность запуска на оборудовании заказчика               |
| Работа некоторых сценариев использования без подключения к сети интернет  |



## Ограничения

|                          Ограничение                           |
| :------------------------------------------------------------: |
|   Простой линии по причине недостатка материалов недопустим    |
|       Материалы и производство в целом может измениться        |
| Производство деталей находится близко к цеху сборке автомобиля |
|            Конкурентный доступ механиков к системе             |
